Quicker: Windows 下的鼠标中键轮盘

发表于2026-09-01|更新于2026-09-01|效率工具

为什么装这玩意

装 Quicker 之前,我每天大概要点 200 次鼠标。其中至少一半是重复的——烧录、复位、开串口助手、抓 log、查手册。点着点着就麻了,跟工厂流水线没区别。

Quicker 就是治这个的。常驻任务栏,按一下鼠标中键,屏幕边缘弹一个轮盘,里面是我提前录好的动作:模拟按键、跑脚本、开应用、贴文本片段,什么都能干。

跟 AutoHotkey 比,它不用写配置文件,动作市场里别人写好的直接装。免费版够我用了。

我每天点的那几个动作

按频率排,前 5 个:

截屏 OCR 提问 — 截一段串口报错,自动 OCR,直接贴到 Claude Code 输入框回车。这是高频动作,基本看到报错就用。1.5 秒走完整个流程,省得我手敲那串十六进制。

STM32 烧录 — 调一次 STM32_Programmer_CLI 烧 .bin。一行命令的事,但每次打开 PowerShell、改路径、敲命令,烦。

串口日志打时间戳 — 复制一段日志,Quick 跑个小脚本给每行加 [HH:MM:SS] 前缀。这个用 Python 写不超过 10 行,放在 Quicker 里就是一键。

复位目标板 — 调 NRST 引脚或者发串口指令。实测下来比按板子上那个 RESET 按钮快多了,尤其是连续调试的时候。

重启串口助手 — 关掉所有 PuTTY / Xshell 再开一份。这种”先全关再开”的操作人手动做要 4 步,Quicker 一步。

剩下还有”复制当前文件路径”、”搜当前窗口内容”、”读 J-Link 序列号”这些,频率没那么高,但配置一次每天省 5 秒,一年就是半小时。

怎么配的

以”烧录 + 开串口”为例:

中键 → 右键轮盘空白处 → 新建组合动作。加两步:

触发键设成中键 + Q,保存。以后按住中键往 Q 上一甩,烧录 + 串口就同时到位。

Quicker 的步骤默认是串行的。可以加等待、提取输出做条件判断——我自己写过个组合:”烧录 → 等 5 秒 → 抓串口前 200 行 → 喂给 Claude Code”,调试协议 bug 时基本不用我自己盯了。

跟 Claude Code 怎么配合

OCR 提问那个动作上面已经说了。再补两个:

预处理日志再喂给 Claude — Quick 里跑一段 Python,把 0x1234 -> 0x5678 这种寄存器错配格式化成可读 diff,Claude 看起来更准。原样贴十六进制有时候它会抓错重点。

代码片段 — Quicker 自带文本面板,我在里面塞了 __WEAK 函数、HAL_UART_RxCpltCallback、DMA 双缓冲这些嵌入式常用的模板,要的时候搜一下粘贴,不用翻旧工程。

安装和坑

官网下载 — Quicker 官网,从顶部工具箱卡片也能进。安装后任务栏会多个图标,右键设置里把”开机自启”勾上。第一次启动会要管理员权限——它要装一个常驻服务用来发键鼠事件,不是恶意。

免费版限 5 个组合动作,专业版 99 元/年。动作组合就是 Quicker 的核心。

OCR 是本地引擎,准确率没云端 API 高,但胜在快 + 离线。真要高准确率,自己接百度 / 腾讯 OCR API,Quick 能调 HTTP。

公司电脑先申请再装——它要常驻服务,有些公司策略不让。Mac / Linux 用户就跳过吧。

怎么开始

刚装别一口气配 50 个动作。我自己的轮盘现在 15 个,已经是极限,再多就要分组或者分页。先配 3 个最痛的:

  1. 时间戳(写日志必备)
  2. OCR 提问(配 Claude Code)
  3. 你最常用的脚本启动(我的是烧录)

一周用下来觉得离不开,再慢慢加。动作太多反而记不住键位,光配置没用上。

还有触发键不要都堆鼠标中键,容易自己按错。中键留给高频的,F1-F12、Ctrl+数字留给低频。
